# 📝 NoteX – Smart Digital Notepad

NoteX is a full-stack Smart Digital Notepad designed to make note-taking simple, organized, and efficient. It allows users to securely manage their notes through a clean and user-friendly interface.

## 🚀 Features

- 🔐 User Registration & Login
- 📝 Create and Manage Notes
- ✏️ Edit Existing Notes
- 🗑️ Delete Notes
- 🔍 Search Notes
- ⭐ Favorite Important Notes
- 📂 Organize Notes by Categories
- 📦 Archive Notes
- 📊 Notes Analytics
- 🌙 Dark Mode
- ☁️ Cloud-Based Database
- 📱 Responsive User Interface

## 🎯 Problem Statement

Traditional note-taking applications often provide only basic functionality and lack efficient organization and management features.

NoteX aims to provide a smarter digital note-taking experience where users can securely create, organize, search, favorite, archive, and manage their notes from one platform.

## 💡 Proposed Solution

NoteX provides a centralized digital workspace for managing notes with authentication, categories, search, favorites, archives, analytics, and other productivity-focused features.

The application uses a full-stack architecture with a web-based frontend, Spring Boot REST API, and cloud-hosted MySQL database.
